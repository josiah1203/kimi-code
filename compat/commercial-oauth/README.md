# Commercial OAuth compatibility archive

This directory contains the former hosted SpiderByte identity, managed model,
usage, feedback, and account OAuth implementation for possible downstream
Business integration. It is intentionally outside `pnpm-workspace.yaml`, the
default build graph, published package contents, and Open Core dependency
closure.

Open Core must not import from this directory or present these implementations
as available local functionality. Hosted identity, managed models, usage,
feedback, and entitlements remain commercial release work and are not claimed
by this repository.

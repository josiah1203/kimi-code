# Excluded commercial implementation

This directory is intentionally outside the pnpm workspace and Open Core
package graph. It preserves the former workspace membership, entitlement, and
hosted-meter implementation for a separately maintained commercial
distribution. The SpiderByte Open Core runtime must not import, register, or
publish this code.

Changes here are not part of the local accountless product contract. Hosted
identity, tenancy, entitlements, billing, and managed usage remain excluded
from this repository's supported release.

# Data sources

The Open Core checkout provides provider-neutral contracts and local tool execution. It does not ship a hosted commercial data source. Add a local or separately maintained provider through a Plugin or MCP server when your workflow needs external data.

Use the [Plugin guide](./plugins.md) to declare a local Skill or MCP server, and keep credentials in the provider's documented secret store. Hosted data catalogs, paid quotas, and account-bound data services are outside this distribution.
